## 1. 新增文件

### 可靠性核心（app/core）

| 文件 | 作用 |
|---|---|
| `app/core/budget.py` | 执行预算：步数/工具/模型/Token/绝对 deadline |
| `app/core/errors.py` | 错误分类、稳定错误码、HTTP 映射 |
| `app/core/retry.py` | 分类重试、指数退避、抖动、Retry-After、deadline 约束 |
| `app/core/circuit_breaker.py` | 三态熔断、单探针、SQLite 共享状态 |
| `app/core/metrics.py` | 计数器与直方图 |
| `app/core/context.py` | request/task/thread 上下文（contextvars） |
| `app/core/observability.py` | 结构化事件、计时、脱敏 |
| `app/core/ratelimit.py` | 滑动窗口限流 |
| `app/core/timeouts.py` | 线程放弃式工具超时（池可重建） |
| `app/core/faults.py` | 仅测试使用的崩溃/故障注入开关 |

## 2. 修改文件

| 文件 | 修改内容 | 原因 |
|---|---|---|
| `app/main.py` | 重写接入层：认证、限流、错误契约、Trace、`/resume`、原子审批、`/ready`、优雅关闭、`/memory` | 原实现无请求治理，审批存在 TOCTOU |
| `app/agents/agent_graph.py` | 固定流程改为 ReAct 循环；预算扣减；检查点；观察回写；故障注入点 | 原图没有"观察后重新决策" |
| `app/services/llm_service.py` | 重写重试/熔断/备用模型/usage 记账/预算；SDK 重试关闭 | 原实现重试分类错误、熔断无半开 |
| `app/services/repository.py` | 心跳、原子状态迁移、请求去重、任务状态统计、busy_timeout | 审批并发与恢复需要 |
| `app/tools/toolkit.py` | 幂等文件命名、对账函数、检索异常显式抛出、`trust` 标记 | 支持副作用一致性与注入防御 |
| `app/services/context_service.py` | 记忆分层、工具目录注入、预算修复 | 原上下文只有词法历史 |
| `app/schemas/tasks.py` | 状态扩展、响应字段、记忆请求 | 支持中断/恢复/预算/观察 |
| `app/core/config.py` | 新增 30+ 可靠性配置 | 让策略可配置、可测试 |
| `app/core/logging_config.py` | JSON 结构化日志 + 上下文 | 原文本日志无法按任务检索 |
| `README.md` | 重写：架构、机制、API、测试、限制 | 原 README 过度描述能力 |
| `.env.example` | 增加预算/重试/熔断/幂等/检查点/限流配置 | 与代码一致 |
| `requirements.txt` | 锁定 LangGraph 1.x、增加 checkpoint-sqlite、移除强依赖 gradio/mcp/redis | 核心可离线安装 |
| `pytest.ini` | 过滤告警、标记 slow | 保持输出干净 |
| `Dockerfile` | 仅安装核心依赖 | 避免 Gradio/MCP 拖慢镜像 |
| `tests/conftest.py` | 临时目录 fixtures、graph/components 工厂 | 测试隔离 |
